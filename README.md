# Pokémon Pokopia — Português de Portugal (Mod)

Traduz o jogo para **português de Portugal**: diálogos, menus, itens e algumas imagens (como o ecrã do título).

**Funciona com:** Pokémon Pokopia versão **2.0.1**, no emulador Eden / Eglantine.

## ⬇️ Descarregar

**[➡️ Descarrega o mod aqui (ficheiro ZIP, em Releases)](https://github.com/kytystudio/pokemon-pokopia-pt-pt/releases/latest)**

Na página, em **Assets**, clica em **`Pokopia_PT-PT_Mod.zip`**. Depois extrai o ZIP e segue os passos abaixo.

> Este mod **não traz o jogo**. Precisas de ter o teu próprio jogo.

> ⚠️ **Só serve para a versão 2.0.1.** Não uses este mod noutras versões do jogo: os textos podem aparecer trocados ou o jogo pode dar erro / não arrancar.
> Para ver a tua versão, abre as definições do jogo: aparece no canto superior direito (por exemplo, "Ver. 2.0.1").

---

## Como instalar (4 passos)

1. **Fecha o jogo e o emulador.**

2. **Copia a pasta `PT-PT`** (a que está junto deste ficheiro) para esta pasta:

   ```
   %APPDATA%\eden\load\0400A3A01EE4C000\
   ```

   > **Dica:** carrega nas teclas **Windows + R**, cola o caminho acima e carrega em **Enter**. Abre-se a pasta certa. Cola lá a pasta `PT-PT`.
   > Se a pasta `0400A3A01EE4C000` não existir, cria-a com esse nome.

3. **Abre o Eglantine.** Clica com o botão direito no Pokopia → **Configure Game** → separador **Add-Ons** → põe visto em **PT-PT** → **OK**.

4. **Arranca o jogo e põe o idioma em `English`.**
   (O mod usa o espaço do inglês para mostrar o português.)

**Pronto!**

---

## Como desativar

Em **Configure Game** (passo 3), tira o visto de **PT-PT**.
Os ficheiros originais do jogo nunca são alterados.

---

## Notas

- Algumas imagens e botões (por exemplo, o ecrã de escolha de idioma) ainda podem aparecer em inglês.
- A tradução foi feita de forma automática e revista; pode haver frases menos felizes.
- Projeto de fãs, não oficial. Pokémon e Pokopia pertencem aos respetivos detentores.
